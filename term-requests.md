# Term requests

**In one line**: concepts this repo needs a term for, terms that are unclear for a case
here, and terms whose label or edge looks wrong, for the `prompts` glossary in
`jburnhams/taxonomies`.

**How**: look the concept up first (`CLAUDE.md`, "Looking up and asking for terms").
If nothing fits, use your own word in the doc now and add a record below by copying the
template. The ID is the date and a slug, unique in this file. The taxonomies repo
collects new records and answers each in
[`domains/prompts/requests.md`](https://github.com/jburnhams/taxonomies/blob/main/domains/prompts/requests.md);
`term.py changes prompts --since <date>` shows the answers. Remove a record once it is
answered. Rules: [`design/growth.md`](https://github.com/jburnhams/taxonomies/blob/main/design/growth.md).

```markdown
### <your word> (`YYYY-MM-DD-<slug>`)

- **Ask**: new | clarify | change
- **Term**: for clarify or change, the ID it is about
- **Concept**: A <your word> is a <nearest broader term> that <what sets it apart>.
- **Looked at**: the terms lookup showed, and why each does not fit
- **Example**: a link to the clearest use in this repo
- **Warrant**: "<your word>" N in *.md, YYYY-MM-DD
- **Asked**: YYYY-MM-DD, <which pass or doc>, <branch or PR>
```
